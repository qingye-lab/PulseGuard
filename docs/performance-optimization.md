# 性能优化与验收范围

本轮继续完成前一轮留下的前端依赖加载、Monaco 本地化和 SQLite 并发/清理优化，不重新打开 [路线图](future-roadmap.md) 中冻结的能力。

## 产品边界

控制台面向桌面与笔记本浏览器，**明确不做手机视口兼容**。不新增手机导航/布局，也不将手机视觉回归列为交付门禁。已有窄屏样式可以保留，但不构成手机支持承诺。UI 探测任务的 H5 页面模式和移动目标视口继续支持。

## 验收清单

- [x] 产品、设计、仓库规则和路线图验收原则明确上述边界。
- [x] Monaco 使用本地按需 ESM 与同源 Worker；打开编辑器前无编辑器资源请求，禁用外网后 Python/JSON 编辑与 JSON 校验可用。
- [x] 总览/监控页的完整静态 JS/CSS 依赖闭包减少，而非仅修改 chunk 名称；图表系列、坐标轴、图例、Tooltip、筛选后更新与重新挂载可用。
- [x] SQLite 只读快照与单写者并行，维护操作独占，异常连接关闭。
- [x] 过期判定保持即时语义，避免无候选查询争用写锁。
- [x] 历史清理按终态 ID 分批原子归档与删除；中断重试不重复累计；运行中记录与两个状态引用受到保护。
- [x] 恢复备份前暂停新接单并等待在途任务，超时不恢复，取消不提前释放保护。
- [x] 完整后端测试、前端构建和桌面渲染验证完成。

## 测量口径

- 比较同一工具链下生产构建的 JavaScript/CSS gzip 字节，计算路由及全部静态依赖并去重；监控页计入立即显示的主图表，不把编辑器等按需资源计入普通路由冷载。
- 包体减少不等于线上响应时间等比例减少。本轮不以本地浏览器速度推算公网 LCP、INP 或吞吐量。
- 后端数据库测试使用初始化的临时数据库，不直接访问实际 `data/pulseguard.db`。浏览器图表验收通过已有本地服务的查询接口读取 7 天历史，并用网络拦截构造分页反例；未主动执行保存、探测、VACUUM、历史清理或恢复。
- 桌面验收覆盖完整桌面与受限桌面窗口；手机不在范围内。

## 运行与维护

数据库连接/归档/恢复的边界和回滚见 [决策记录](decisions/2026-09-04-local-runtime-and-sqlite-concurrency.md)。上线前应核对 Python 实际链接的 SQLite 版本；本地验证环境为 3.49.1，并非官方 WAL-reset 修复版。主机运行时升级和真实数据库压缩仍需独立运维操作。

## 实测结果（2026-09-04）

### 前端

同口径统计包含共享 JS/CSS，单位为 gzip 字节；监控页包含立即加载的主图表：

| 路由闭包 | 优化前 | 优化后 | 减少 |
| --- | ---: | ---: | ---: |
| 应用入口 | 459,424 | 263,697 | 42.6% |
| 总览冷载 | 463,257 | 368,182 | 20.5% |
| 监控趋势冷载 | 905,519 | 673,086 | 25.7% |

`npm run build` 通过（含双 TypeScript 检查），构建时自动执行闭包预算与编辑器资源边界校验；产物报告为 `frontend/dist/.vite/bundle-budget.json`。`npm run test:bundle` 的 11 项测试通过，覆盖共享依赖/样式、隐藏预算回归、图表注册表泄漏、编辑器泄漏、缺失/伪本地 Worker。

保留 Vite 的 500 KB 通用 chunk 警告，没有提高阈值隐藏它：本地 Monaco 主运行时约 3.72 MB 原始 / 964 KB gzip，仅打开编辑器后加载。实际路由预算分别为入口 300 KB、总览 400 KB、监控页 700 KB（gzip）。没有升级依赖版本；将既有 G2 5.4.8、Monaco 0.55.1 声明为直接依赖，并移除不再使用的 `@ant-design/plots` 外层。

Monaco 验证在外网拦截、API mock 的 Edge 中进行：列表没有 editor/worker 请求；JSON、Python 和纯文本均可输入，Python 高亮与非法 JSON 诊断正常；捕获的 34 个请求均同源，console 无 error/warning。

图表验证覆盖真实只读历史、三条合成指标曲线及零值、Tooltip、详情点位/图例、13 条合成任务的 12+1 分页、5 次快速周期切换、卸载后重新进入；无残留 canvas 和 console error/warning。桌面窗口使用 1440×900、1024×768；截图保留在 `output/playwright/`（已忽略，不进入版本控制）。

最终生产版本的监控页、趋势抽屉、JSON/Python 编辑器截图已由主任务目视复核。1024px 摘要使用三列，数字不再拆行且无页面横向溢出；1440px 使用五列。坐标标签使用设计 token 的原色，避免与图表默认透明度叠加后过淡。首屏直接呈现筛选、当前指标和工作内容。所有未保存编辑均已放弃，验证用浏览器和自建前端服务已关闭，原有 8787 服务保留。

### 后端

`uv run python -m unittest discover -s backend/tests -p 'test_*.py' -v`：**416 项通过，26.408 秒**，使用独立初始化临时库。另通过 `uv lock --check --offline`，确认 Dockerfile 继续使用 `uv.lock` / `uv sync --frozen` 及前端 `npm ci`。未进行 Docker 构建或部署。

新增测试证明读快照跨提交一致、读写并行、读连接不能写入、异常回滚并关闭、维护排他及重入边界、备份损坏拒绝、恢复失败补偿/双失败保持暂停、重复取消保护、孤儿本地子任务与 Worker 排空、运行时配置重载失败保持暂停。

1201 条过期记录的归档批次精确为 `[500, 500, 201]`；重复清理返回 0，第二批故障后重试不重复累计。既有临时数据库缺索引时连续初始化两次通过，实际清理 SQL 使用 `idx_runs_cleanup_terminal`，没有临时排序。实际部署前仍须针对活动数据库的一致性副本执行初始化预演。

合成锁竞争实验使用 1200 条运行记录、写事务持锁 250ms、5 次中位数：

| 查询 | 模拟旧全局锁 | 新只读快照 |
